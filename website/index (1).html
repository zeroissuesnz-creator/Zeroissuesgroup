A few useful details.

Can I connect any booking system?

Not automatically yet. The current version imports financial CSVs with the required booking fields. Each live provider connection needs its own supported integration.

Does StayLedger post straight into Xero?

No. It prepares reconciliation CSVs and a draft sales CSV for review. Account codes, GST treatment, fees, refunds and existing entries need checking before import.

Where is my login?

The hosted pilot is currently private. Existing permitted testers can use the pilot link below. The public demo does not have account saving.

Does the demo save my information?

The public demo keeps records only in the current browser tab. Download your reconciliation before closing or refreshing. The separately hosted pilot has account-based saving.
